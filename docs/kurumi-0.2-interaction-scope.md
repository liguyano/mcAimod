# Kurumi 0.2.0 客户端交互扩展规格

状态：设计记录，尚未实现或构建 JAR。

## 已确认需求
- 纯客户端 NeoForge Mod；其他玩家及服务器不必安装。
- 所有玩家公共聊天自然提到 kurumi 即可唤醒，无需 @；先以本玩家账号回应，再自动处理，不需要二次确认。
- 支持聊天、Baritone 农作和停止、靠近玩家、使用床、开门、按按钮。
- 支持拾取地面物品、按指定名称和数量丢弃物品、从附近可访问箱子拿取和存放指定物品。
- **暂不支持合成物品**。

## 箱子交互
客户端通过正常游戏流程靠近并右键箱子，等待服务器同步容器界面，读取可见槽位，通过正常容器点击移动指定数量物品，再验证服务端更新。无需服务器安装本 Mod，但不能绕过箱子锁、领地权限或服务器限制。失败或物品不足时停止并报告。

## 安全边界
- 仅允许指定物品和明确数量，拒绝模糊的清空箱子或全部丢弃请求。
- 默认禁止丢弃贵重、附魔或特殊命名装备。
- 一次只执行一个任务；设置超时、冷却和本地紧急停止命令。
- 公共聊天、自动动作、背包动作、容器动作均独立开关，初始默认关闭。
- 模型只能产生结构化候选动作，必须经过客户端白名单验证；禁止执行任意聊天文本、命令或脚本。

## 实现顺序
1. 客户端聊天监听、唤醒、先回应和限流。
2. Baritone 农作与停止。
3. 使用床、门、按钮。
4. 地面拾取、背包指定数量丢弃。
5. 箱子指定物品和数量的取放及结果验证。

本文是开发规格，不代表已经实现或发布 0.2.0。
