# Kurumi Web 无密码访问

Kurumi Web 面板监听 `0.0.0.0:8765`。当前已移除登录页面、密码验证与会话令牌校验，打开面板的任何人均可查看任务、执行脚本以及新增、编辑和删除技能及快捷触发词。

**安全提醒：** 如果你通过 cpolar 将 8765 映射到公网，任何知道公网地址的人都可能操作 Minecraft 客户端。建议在隧道服务侧设置访问控制，或仅通过可信 VPN / 局域网暴露端口。不要在公网无遮拦地运行脚本执行功能。原 `config/mcaimod-web.json` 不再被读取，可自行保留或删除。

技能脚本依然受 Kurumi 原有解释器的白名单与运行限制约束，但这不等于访问授权。
