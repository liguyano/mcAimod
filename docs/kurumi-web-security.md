# Kurumi Web 密码与技能管理

Kurumi Web 面板监听端口 8765。登录后才能查看任务状态、生成/执行脚本，以及查看、手动新增、编辑或删除技能和快捷触发词。

## 设置密码

在当前 Minecraft 实例的 `config` 目录创建 `mcaimod-web.json`：

```json
{
  "password": "在这里填写自己的密码"
}
```

也可以在启动 Minecraft 的进程环境中设置 `MCAIMOD_WEB_PASSWORD`，环境变量优先于配置文件。不要把真实密码提交到 Git。

登录成功后会获得内存中的随机会话令牌，有效期 8 小时；服务重启后令牌失效。连续输错 5 次会暂时限制该来源地址的登录。

## 安全提示

服务仍绑定 `0.0.0.0:8765` 以供局域网访问。当前 HTTP 连接没有 TLS，因此密码在网络传输中没有加密；仅在可信局域网或 VPN 内使用，不要把 8765 直接转发到公网。密码保护不能替代网络隔离。

## 技能管理

Web 技能表单使用同一份 `mcaimod-skills.json`。保存前会经过受限解释器解析和技能命名/触发词冲突校验；触发词留空表示只保留技能、不创建快捷指令。修改已有技能会保留最近版本历史。手动新增或修改在密码认证成功后直接保存，不再额外要求游戏内确认。
