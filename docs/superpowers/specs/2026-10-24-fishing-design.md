# Kurumi v0.4.0 自动钓鱼设计

## 目标

主人要求钓鱼时，Kurumi 从背包装备鱼竿，搜索当前加载区域最近的大型开放水域，安全寻路到岸边，抛竿、检测咬钩、收竿并重复。钓鱼默认持续运行，直到主人明确停止、模型改变任务或安全条件触发。

## 设计选择

- 方案一（采用）：Minecraft 原生鱼竿交互与客户端 tick 状态机；Baritone 仅负责岸边寻路。鱼钩真实存在后才判定抛竿成功。
- 方案二：让模型生成 `sleep` 和鼠标右键循环；无法依据真实咬钩时机，不采用。
- 方案三：依赖其他自动钓鱼 Mod；额外依赖与版本兼容难保证，不采用。

## 边界

- `fish()` 启动后台任务并立即返回脚本结果，使 Agent 仍可与玩家交谈；`stop_fishing()` 和 `/kurumi stop` 可取消。
- 只使用背包内原有钓竿，不自动制造鱼竿。不使用网络封包伪造服务器结果。
- 搜索半径水平24格、垂直8格，要求至少25格连续水面与足够的开放表层；寻找有两格站立空间、稳固地面的安全岸边。
- 使用 Baritone 禁止破坏方块的寻路；验证实际靠近岸边才抛竿。
- 鱼漂出现后使用已稳定的鱼漂向下冲量作为咬钩信号；不以发出交互命令当成钓到鱼。
- 每次收竿后检查背包变化、鱼竿耐久和鱼漂状态；失败后限次重试，背包满、鱼竿损坏、无水域、寻路超时、连续多次无咬钩均安全停止并记录原因。
- 主动钓鱼与新世界操作不能冲突，模型在改变任务时应先调用 `stop_fishing()`。
- 版本升至0.4.0，NeoForge 基线保持26.2.0.88。
